# Подсказки MreTips

Отдельный Rocket-плагин рассылает по одной подсказке в общий чат. Первый показ — через полный интервал после загрузки; по умолчанию 300 секунд. Подсказки идут по кругу, при пустом сервере пропускаются без перехода к следующему тексту. После задержки сервера пропущенные сообщения не догоняются. После перезагрузки цикл начинается заново.

Rocket создаёт конфигурацию плагина при первой загрузке. `Enabled` отключает рассылку, `IntervalSeconds` задаёт интервал от 60 до 86400 секунд, `Messages` — список текстов. Пустые строки пропускаются; каждая непустая запись должна быть однострочной и не длиннее 160 символов. Пустой список отключает сообщения. Изменения конфигурации применяются после перезагрузки плагина. При изменении других плагинов и прав проверяйте актуальность текстов вручную.

Сборка: `powershell -File scripts/Build-MreTips.ps1`. Результат и манифест — `runtime/builds/MreTips`; скрипт не устанавливает плагин. Просмотр установки: `powershell -File scripts/Install-MreTips.ps1`; установка при остановленном сервере: `powershell -File scripts/Install-MreTips.ps1 -Apply`. Установщик сохраняет существующую конфигурацию и резервирует старую DLL. Проверка расписания: `dotnet run --project src/MreTips/Tests/MreTips.Tests.csproj`.

02.11.2026 плагин установлен на локальный сервер: Rocket загрузил его и создал конфигурацию с `Enabled=true`, `IntervalSeconds=300`. Расписание прошло автоматические проверки; фактическое отображение сообщения в игровом чате ещё требует приёмки с игроком.
