# Геометрия зон MRE

`PolygonZone` проверяет принадлежность точки X/Z простому полигону; границы включены. Полигоны задаются без повторения первой вершины, с уникальными координатами в диапазоне ±1 000 000. Самопересечения, наложение соседних рёбер и нулевая площадь отклоняются. Пустой набор зон и некорректные координаты запроса вызывают исключение: вызывающий код обязан трактовать их как неизвестное состояние и не применять гниение. При пересечении зон `ZoneSet` возвращает все совпадения по порядку имён ordinal; настройка приоритета гниения здесь не задаётся. Сравнения точные, без допуска; данные границ необходимо проверять в игре.

Координаты и размеры городских зон PEI не утверждены и в проект не внесены. Модуль не подключён к серверу и не меняет игровой мир. Проверки: `dotnet run --project tests/MreDecayZones/MreDecayZones.csproj`.
