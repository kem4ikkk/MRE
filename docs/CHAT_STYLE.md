# Оформление сообщений чата MRE

## Реализовано

- Серверные сообщения получают единый префикс `[MRE]`; сообщения администрации и персонала — красный `[MRE-ADMIN]`.
- Для разделов HOME, TPA, наборов, обмена, хранилища, голосования, аирдропа, персонала и админки добавляется цветная подпись раздела.
- Существующие игровые сообщения игроков остаются без изменений. Поддержаны старые префиксы и заголовки HOME/TPA.
- Созданы десять оригинальных PNG-иконок 32×32 в `assets/chat-icons/`; скрипт для их повторной генерации — `scripts/Build-MreChatIcons.ps1`.
- Конфигурация MreChatStyle поддерживает отдельный HTTP(S)-URL иконки для каждого раздела и общий запасной логотип.

## Иконки

Клиент Unturned загружает иконку по URL. После публикации PNG в репозитории настройки MreChatStyle по умолчанию указывают на `assets/chat-icons/*.png`; каждому разделу назначена своя иконка. Общий запасной вариант — текущий логотип MRE. При переопределении URL в конфигурации используйте публичные HTTP(S)-ссылки.

## Шрифт и проверка

Цвета, жирное начертание и короткие подписи задаются Rich Text Unturned. Игра продолжает использовать свой шрифт, масштаб и разметку чата; серверный плагин не может гарантировать одинаковый вид на разных разрешениях и настройках клиента. Требуется визуальная проверка в подключённом игровом клиенте.

Модуль и тесты форматирования собираются локально. Установка DLL требует остановить сервер и выполняется скриптом `scripts/Install-MreChatStyle.ps1` с резервной копией текущих DLL и переводов. Во время подготовки сервер был запущен и отвечал с одним подключённым игроком, поэтому его работа не прерывалась.

## Следующие шаги

1. Дождаться, когда на сервере не останется игроков, и установить собранные плагины скриптом установки.
2. Проверить загрузку модулей в журнале сервера и визуально проверить сообщения в клиенте.
3. После установки проверить, что игровые клиенты загружают PNG с GitHub и показывают их в чате.
