## Применение списка

```powershell
# Только показать будущий список; серверные файлы не меняются.
.\scripts\Set-MreWorkshop.ps1

# Применить к уже сгенерированному конфигу остановленного MRE.
.\scripts\Set-MreWorkshop.ps1 -Apply

# После отдельной проверки добавить транспорт.
.\scripts\Set-MreWorkshop.ps1 -Apply -IncludeVehicles
```

Скрипт берет декларацию из [config/workshop.json](../config/workshop.json), объединяет `File_IDs` с существующим `WorkshopDownloadConfig.json`, сохраняет остальные свойства и делает копию прежнего файла. Отсутствие `-IncludeVehicles` удаляет управляемый ID William's Vehicles из списка; посторонние ID сохраняются. Удаление мода с уже созданными предметами требует отдельного решения о мире и копии сохранений. На работающем сервере применение запрещено.

## Что подтверждено об автодонате REDLINE

Публичный список REDLINE содержит `GameStoresUnturned` и `RedLineBuyCommands`; витрина размещена на GameStores. [Сам сервис](https://gamestores.app/) заявляет продажи на серверах Unturned с Rocket. Это подтверждает выбор платформы интеграции, но не раскрывает настройки выдачи REDLINE, сроки, обработку повторов и отзыв прав.

В MRE автодонат остается отдельным этапом: аккаунт владельца, действующий платежный метод, официальный модуль, права, журнал заказов и проверки повторной выдачи/истечения. Секреты не хранятся в Git и не передаются в чат. До подключения и испытаний нельзя объявлять работающую автоматическую выдачу.

## `/vote day`

Одного имени `Voter` в публичном списке REDLINE недостаточно, чтобы подтвердить точный синтаксис `/vote day`, процент голосов, cooldown, цену или доступ по рангу. Исходники и конфигурация REDLINE не получены; фактическое поведение команды там остается непроверенным.

Для MRE разрабатывается самостоятельный небольшой плагин **MreEssentials** с исходниками и MIT-лицензией. Планируемый контракт: `/vote day` начинает голосование ночью и отдает голос инициатора, повторная команда или `/vote yes`/`/cv` голосуют; `/vote status` показывает счет. Минимум два игрока, порог 60% от снимка участников в момент старта, длительность 60 секунд, перерыв 300 секунд. Уникальный SteamID дает один голос. Вошедшие после начала не меняют состав голосования; отключившиеся не уменьшают требуемый порог. Каждый учетный день и кворум проверяются отдельно.

Плагин также обеспечивает `Save` каждые 300 секунд на главном игровом потоке, только после загрузки уровня. Параметры настраиваются; автосохранение не заменяет внешнюю резервную копию. Факт компиляции не равен проверке в игре двумя клиентами. Состояние установки и прогона фиксируется координатором в актуальном отчете.

## Подготовка, выполненная 29.10.2026

- Скрипты Workshop и сборки прошли синтаксическую проверку Windows PowerShell 5.1 и сохранены UTF-8 с BOM.
- На изолированном JSON-файле проверены предпросмотр без записи, включение транспорта, его управляемое отключение, сохранение постороннего ID/неизвестных свойств и отказ при занятой блокировке обслуживания.
- MreEssentials 0.1.0 скомпилирован по установленному U3DS и скопирован в каталог плагинов остановленного MRE. Конфигурация создается Rocket при первом запуске.
- Выполнены 42 изолированные проверки кворума, локального канала и runtime-диагностики: повторы голосов/запросов, поздний вход, выход участника, таймаут, запрет посторонних команд, отмена старых запросов, подтверждение Shutdown до исполнения, независимость пути control от изменяющегося рабочего каталога игры и обработка отсутствующих reflection API без падения.
- Вход чистого клиента, предметы/рецепты More Farming, транспорт и голосование двух реальных игроков здесь еще **не проверены**. Координатор отдельно фиксирует серверный запуск и установку Workshop.
