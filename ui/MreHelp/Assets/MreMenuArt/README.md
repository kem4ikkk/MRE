# Ресурсы меню MRE

Действующая оболочка использует `server-logo.png` и папку `shell/`. `server-logo.png` — неизменённая копия `assets/mre-server-logo-transparent.png`; исходник и копия имеют одинаковый SHA-256. Рекомендуемый размер логотипа — 72 px.

В `shell/` находятся оригинальные PNG-иконки из собственного SVG-макета и белые маски скруглений для Unity nine-slice. Команды воспроизведения и происхождение описаны в `shell/README.md`. Сторонние наборы пиктограмм и закрытые ресурсы других серверов не использовались.

Шрифты Noto Sans Regular/SemiBold хранятся отдельно в `Assets/MreFonts`, с лицензией SIL Open Font License 1.1. Синтетическое утолщение отключено.

На оригинальные изображения меню отдельная открытая лицензия не назначена; они распространяются как материалы проекта MRE. Не приписывайте им лицензию стороннего набора иконок.
