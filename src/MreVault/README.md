# MreVault — изолированный прототип

Статус: только журнал подготовки операций; игровой `/s`, UI, перенос предметов, фиксация и восстановление не реализованы. Не устанавливать на сервер. Подтверждённый пользователем базовый размер — 4×4 клетки. Основа требований — ветка `feature/start-kit-chat-icon`, изученная через GitHub; это отдельный каталог, не git checkout.

`Prepare` копирует переданные снимки, ограничивает совокупный размер записи 1 МиБ, проверяет владельца, начальные координаты, повторение начальных позиций и сохранение количества, качества и байтов состояния предметов между двумя сторонами. До передачи должна выполняться независимая проверка площади предметов и пересечений по реальным ItemAsset. Адаптер обязан получить согласованные снимки на игровом потоке; копирование не гарантирует согласованности, если исходные объекты меняются одновременно в процессе копирования.

Файловый `CreateNew` допускает одну незавершённую операцию на SteamID; pending сохраняется и при ошибке записи. Версия формата и SHA-256 проверяются при чтении; повреждение не снимает блокировку. `Flush(true)` запрашивает запись данных, но не доказывает устойчивость операции создания каталожной записи после отключения питания на любой файловой системе. Автоматического снятия pending нет.

Авторитетного сохранённого состояния и CAS пока нет: код намеренно допускает только операцию из пустого состояния версии 0. Вторую операцию или восстановление не реализует. Нужно проверить долговечный checkpoint на выбранной ОС, разработать атомарное обновление состояния и ручную сверку журнала с игровыми сохранениями. Синхронная запись журнала не объединяет хранилище и игровой инвентарь в транзакцию; авария может оставить неопределённый результат, который надо разбирать без повторной выдачи.

Для реального `/s` также нужны: проверенный адаптер инвентаря и UI, блокировка combat/raid при открытии и каждой операции, закрытие или заморозка открытого окна при бою, смерти, отключении и выгрузке, проверка устаревших callbacks, backup/restore и сценарии V01–V09 и X01–X07 из `docs/ACCEPTANCE_CHECKLIST.md`. Платные объёмы не добавлены.

Проверки журнала: `dotnet run --project src/MreVault/Tests/MreVault.Tests.csproj`. 31.10.2026 изолированные проверки журнала прошли на .NET SDK 8.0.427 в Debian 13. Интеграция с U3DS и игровые проверки не выполнялись; к данным игроков этот прототип не подключён.
