# Оформление сообщений чата MRE

## Реализовано

- Серверные сообщения получают единый префикс `[MRE]`; сообщения администрации и персонала — красный `[MRE-ADMIN]`.
- Для разделов HOME, TPA, наборов, обмена, хранилища, голосования, аирдропа, персонала и админки добавляется цветная подпись раздела.
- Обычные системные ответы используют `system.png`, а ответ на неизвестную команду — логотип MRE: `[MRE] Команда не найдена.`
- Существующие игровые сообщения игроков остаются без изменений. Поддержаны старые префиксы и заголовки HOME/TPA.
- Созданы десять оригинальных PNG-иконок 32×32 в `assets/chat-icons/`; скрипт для их повторной генерации — `scripts/Build-MreChatIcons.ps1`.
- Конфигурация MreChatStyle поддерживает отдельный HTTP(S)-URL иконки для каждого раздела и общий запасной логотип.

## Иконки

Клиент Unturned загружает иконку по URL. Настройки MreChatStyle по умолчанию указывают на `assets/chat-icons/*.png`; каждому разделу назначена своя иконка. Ответ «Команда не найдена» намеренно использует логотип сервера вместо `system.png`, а обычные системные сообщения сохраняют свою иконку. При переопределении URL в конфигурации используйте публичные HTTP(S)-ссылки.

## Шрифт и проверка

Цвета, жирное начертание и короткие подписи задаются Rich Text Unturned. Игра продолжает использовать свой шрифт, масштаб и разметку чата; серверный плагин не может гарантировать одинаковый вид на разных разрешениях и настройках клиента. Требуется визуальная проверка в подключённом игровом клиенте.

Модуль и тесты форматирования собираются локально. Скрипт `scripts/Install-MreChatStyle.ps1` установил обновления с резервной копией в `runtime/backups/chat-style-install-20261105-050640-0441`. Rocket зарегистрировал MreChatStyle, сервер загрузил PEI и прошёл локальную проверку A2S на 24 слота. MreTrade собран, но не установлен, поскольку он отключён в текущей конфигурации.

## Следующие шаги

1. После установки обновления визуально проверить сообщения и иконки в подключённом игровом клиенте: серверный тест не подтверждает рендеринг UI на клиенте.
2. В будущем логотип сервера также можно назначить приветствию игрока, ответу `/help` или объявлению о перезапуске; сейчас они не менялись.
3. Если GitHub блокируется сетью клиента, задать доступный HTTPS-хост для URL иконок в конфигурации MreChatStyle.
