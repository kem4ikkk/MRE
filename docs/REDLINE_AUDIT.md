# REDLINE → MRE: аудит публичной части проекта

Дата исследования: **28 октября 2026 года**. Основной референс по выбору владельца MRE — **REDLINE #1 на PEI, выживание, MAX4**. REDLINE #6 рассмотрен для сравнения. Денежные суммы в этой записке не выдумываются: подтвержденного прайса REDLINE получить не удалось.

## 1. Что именно удалось проверить

Изучены публичные карточки серверов, индексируемая витрина GameStores, описания Workshop и ссылки, опубликованные владельцем REDLINE. Подключение игровым клиентом, покупка товаров и доступ к административной панели не выполнялись. Дата исследования означает дату чтения; отдельные поисковые снимки старше этой даты.

Используются четыре уровня достоверности:

| Метка | Значение |
|---|---|
| Первичный источник | Описание автора Workshop или собственная витрина проекта |
| Публичная телеметрия | Сведения, полученные мониторингом от сервера; возможны задержки и ошибки интерпретации |
| Заявление владельца | Рекламное описание или ссылка владельца, а не независимая проверка |
| Проектное решение MRE | Наше предложение, которое не следует приписывать REDLINE |

Открытый аудит достаточен для создания функционально похожего MRE. Он не раскрывает исходники, настройки каждого плагина, доходы, договоры и внутренние процедуры REDLINE.

## 2. Два PEI-сервера нельзя смешивать

| Параметр | REDLINE #1 — основной референс | REDLINE #6 — сравнение |
|---|---|---|
| Адрес игрока | `185.189.255.167:23000` | `185.189.255.167:25550` |
| Карта | PEI | PEI |
| Режим по телеметрии | PvP, Easy, обе камеры | PvP, Normal, обе камеры |
| Группа | MAX4 | MAX6 |
| Лимит слотов | 48 | 48 |
| Акцент названия | TPA, HOME, VAULT | SHOP, KITS, LootX2 |
| Обозначение витрины | 1XLOOT | 2XLOOT |

Источники таблицы: [карточка #1](https://www.restoremonarchy.com/servers/85568392924629545), [карточка #6](https://www.restoremonarchy.com/servers/85568392924649795), [витрина REDLINE](https://redlineserver.gamestores.app/).

Владелец #1 сообщает о хранилище ценных вещей и перезапуске в 06:00 МСК. Это полезные ориентиры сервиса. Заявление об отсутствии дисбалансного доната требует проверки содержимого магазина. [Описание владельца #1](https://www.restoremonarchy.com/servers/85568392924629545).

**Решение MRE:** проектировать один сервер выживания MAX4. Механики экономики и ускоренного PvP из #6 не включать автоматически.

## 3. Важное отличие маркетинга от настроек

У #1 витрина использует 1XLOOT, а мониторинг вычисляет Loot ×1.43 normal. В объявляемой конфигурации присутствуют следующие значения:

| Поле #1 | Значение |
|---|---:|
| `Gameplay.Max_Group_Members` | `4` |
| `Gameplay.Ballistics` | `true` |
| `Items.Spawn_Chance` | `0.5` |
| `Players.Spawn_With_Max_Skills` | `true` |
| `Structures.Armor_Hightier_Multiplier` | `0.4` |
| `Structures.Armor_Lowtier_Multiplier` | `0.4` |

Это выборочные фактические параметры, а не готовый конфиг для копирования. Полный публичный фрагмент доступен в [карточке #1](https://www.restoremonarchy.com/servers/85568392924629545). Для MRE нужно отдельно измерить плотность лута и время рейда: слово «1x» не является точным техническим заданием.

Показатель Home teleport в сводке мониторинга не доказывает задержку команды конкретного плагина. Время прогрева, cooldown, отмену движением и блокировку в бою необходимо проверить игровым клиентом.

## 4. Workshop #1 и возможность использования в MRE

По публичной телеметрии у #1 на момент чтения объявлены пять Workshop-компонентов общим размером около 297,5 MB; у #6 отсутствуют два общедоступных расширения выживания. Размеры относятся к снимку мониторинга и могут отличаться от Steam из-за версии и единиц измерения. [Источник #1](https://www.restoremonarchy.com/servers/85568392924629545), [источник #6](https://www.restoremonarchy.com/servers/85568392924649795).

| Компонент | Workshop ID | Что известно и решение для MRE |
|---|---:|---|
| More Farming Mod | `1232252658` | Оригинал Dogfood: хозяйство, еда, мебель, стаки ресурсов; кандидат для тестовой сборки MRE. [Описание автора](https://steamcommunity.com/sharedfiles/filedetails/?id=1232252658) |
| [Pre-V3-1] William's Vehicles | `3485061773` | Автор WW_TC описывает транспорт со спавном на официальных картах; кандидат для отдельной проверки. [Страница автора](https://steamcommunity.com/sharedfiles/filedetails/?id=3485061773) |
| RedLine | `1991009929` | Автор Vega_Punk прямо ограничивает назначение модификации проектами REDLINE/PredeL. В сборку MRE без отдельного разрешения не включать. [Описание автора](https://steamcommunity.com/sharedfiles/filedetails/?id=1991009929) |
| RedLine UI | `2874498147` | Эффекты для плагинов REDLINE; наличие публичной страницы не доказывает право на перепаковку или использование интерфейса в MRE. [Описание](https://steamcommunity.com/sharedfiles/filedetails/?id=2874498147) |
| RedLineHalloween | `3827785539` | Привязка имени к ID найдена в фильтре мониторинга; содержание и разрешения первоисточника не проверены. Для запуска MRE не нужен. [Фильтр с modId](https://www.restoremonarchy.com/servers?modId=3827785539&plugin=imperialpluginsloader) |

У RedLine заявлены собственные сейфы и упаковки материалов. Для MRE на первом этапе можно проверить стаки More Farming и использовать обычные игровые хранилища вместе с отдельным vault. Это наше предложение по сокращению затрат, а не утверждение об эквивалентности предметов.

У William's Vehicles в комментариях есть вопрос Vega_Punk о допустимости установки на сервер и утвердительный ответ автора. Это подтверждает обычное серверное использование; оно не разрешает перепубликовать мод от своего имени. [Переписка на странице автора](https://steamcommunity.com/sharedfiles/filedetails/?id=3485061773).

More Farming предупреждает о необходимости совпадения обновленных серверных Workshop-файлов с клиентом. Оригинальная версия и отдельные Core/Vanilla Maps-переделки — разные зависимости: в MRE выбирать одну согласованную схему и проверять ее на чистом клиенте. [Оригинал](https://steamcommunity.com/sharedfiles/filedetails/?id=1232252658), [отдельная Core-версия](https://steamcommunity.com/workshop/filedetails/?id=3729650953).

## 5. Серверные плагины: что видно снаружи

В телеметрии #1 присутствуют, среди прочих, `Kits`, `MoreHomes`, `Storage`, `GameStoresUnturned`, `AirdropManager3`, `Moderation`, `RespawnProtection`, `BackTurnedSharedStorage`, `RedLineTpa`, `RedLineRaidPvPBlock`, `RedLineNightDamage`, `RedLineBuildDecay`, `RedLineTrade`, `RedLineHUD`, `RedLineMenu`, `RedLineCheck`, `RedLineAdminGuard`. Полный актуальный перечень следует смотреть непосредственно в [карточке #1](https://www.restoremonarchy.com/servers/85568392924629545).

У #6 дополнительно видны `AdvancedEconomy`, `Uconomy`, `RedLineCoinFlip`, `RedLineMath`; его состояние не следует переносить на #1. [Карточка #6](https://www.restoremonarchy.com/servers/85568392924649795).

Имя DLL подтверждает только то, что сервер объявляет это имя. Оно не раскрывает версию, автора, лицензию, активность функции, команды и внутренние правила. Названия `RedLine*` — основание предположить собственные доработки, но не доказательство, что соответствующий код невозможно легально приобрести. Доступ к этим исходникам в ходе аудита не получен.

Техническая карточка показывает версию framework, но классифицирует его как None/Other. Поэтому версию и форк загрузчика REDLINE считать неизвестными. Для MRE выбирать поддерживаемый стек независимо, а затем проверять совместимость требуемых плагинов.

## 6. Карта механик для проектирования MRE

Следующая таблица — **наша декомпозиция для разработки**, а не восстановленная конфигурация REDLINE. Названия компонентов используются как ориентиры для последующей проверки.

| Подсистема | Что нужно узнать у референса | Какое минимальное решение подготовить MRE |
|---|---|---|
| Телепорты | Число домов, задержки, расстояние до противника, cooldown, отмена | Один модуль TPA/Home с сохранением точек и запретом обхода боя |
| Vault | Размер сетки, число хранилищ, сохранение после смерти/вайпа, предметные запреты | Одно устойчивое хранилище; права расширений через роли |
| Наборы | Стартовый kit, периодичность, ограничения покупки, заполняемость инвентаря | Небольшой бесплатный набор; платные наборы после проверки баланса |
| Группа | Подсчет союзников вне Steam-группы, наказание за обход MAX4 | Лимит 4 и понятные правила против объединения групп |
| Рейды | Допустимые часы, защита новичка, блок телепорта, ночной урон | Опубликовать одно понятное правило; не обещать защиту без реализации |
| Постройки | Decay, лимиты объектов, урожай, транспортные баррикады | Консервативные лимиты, журнал действий и резервирование мира |
| Предметы | Сейфы, стаки, улучшения, измененные характеристики | Сначала ваниль и проверенные общедоступные расширения |
| Интерфейс | HUD, меню, killfeed, язык, модальные окна | Команды и тексты; собственный UI только после устойчивого запуска |
| События | Аирдропы, ежедневные награды, сезонные события | Регулярный бесплатный ивент без случайных платных призов |
| Модерация | Репорты, проверка жалоб, апелляции, действия админа | Человек принимает решения; автоматизация собирает материалы |
| Магазин | Оплата, выдача, срок роли, продление, возврат, сбой сервера | Готовая витрина и надежная очередь выдачи с журналом |

Экономия достигается сокращением числа индивидуальных доработок. Предварительно нельзя считать, что один универсальный бесплатный плагин повторит все перечисленные подсистемы без настройки и сопровождения.

## 7. Донат REDLINE: подтверждено и неизвестно

Индексируемая витрина содержит выбор серверов #1–#6 и категории: игровая валюта, подписки, наборы, команды, предметы. Однако карточки товаров в доступном снимке не загрузились: отображалось `No data available`. [Витрина REDLINE](https://redlineserver.gamestores.app/).

Поэтому сейчас **не подтверждены**:

- Названия рангов, цены в рублях и сроки действия.
- Состав kits и количество предметов.
- Цены расширения vault, число домов, отдельные платные команды.
- Скидки, промокоды, кешбэк и условия пополнения баланса.
- Сохранение покупок после вайпа, продление роли, возвраты.
- Реальная комиссия платежей и доход проекта.

Пустой результат загрузки не означает, что в магазине нет доната. Также категории общей витрины не доказывают, что все они доступны именно на #1.

Для MRE допустимо повторить **модель**: доступ на сервер бесплатно, понятные платные роли и возможности, автоматическая выдача. Конкретный прайс MRE должен быть отдельным проектным решением с расчетом себестоимости и тестом спроса. Нельзя представлять предложенные цены MRE как восстановленный прайс REDLINE.

## 8. Сообщество, правила и вайпы

Владелец указывает [VK REDLINE](https://vk.com/unturned_redline), [Discord](https://discord.gg/nqYvCtKn2P) и [страницу правил](https://vk.com/pages?hash=86e8232a1d2842f38e&oid=-174196607&p=%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0_%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B0). Привязка сообщества и Discord дополнительно присутствует у [автора Workshop RedLine](https://steamcommunity.com/sharedfiles/filedetails/?id=1991009929).

Содержание VK и Discord прочитать не удалось. Расписание вайпов, полный список запретов, процедура апелляции, история мероприятий и размер активного сообщества остаются непроверенными. Ежедневный перезапуск не равен вайпу.

Для MRE потребуется собственный документ: MAX4, союзы, рейды, строительство, запрещенные программы и баги, порядок жалоб, санкции, апелляции, полномочия модераторов, сохранение покупок при вайпе. Правила референса полезно изучить, но текст MRE нужно написать под реальные настройки MRE.

## 9. Как закрыть пробелы обычным игроком

Рабочая оценка дополнительного ручного исследования: **2–4 часа за несколько заходов**. Длительное наблюдение за удержанием игроков и вайпами потребует отдельных дней.

| Проверка | Действие без покупки | Что сохранить |
|---|---|---|
| Вход новичка | Зайти на #1 чистым клиентом | Время загрузки, фактические Workshop ID, приветствие, команды |
| Механики | Прочитать `/help`, меню, `/kits`; опробовать доступные TPA/Home/Vault | Дословные параметры, права бесплатного игрока, видео или заметки |
| Телепорт | Проверить отмену движением и поведение во время безопасной согласованной дуэли | Warmup/cooldown отдельно, условия отказа |
| Хранилище | Положить тестовый недорогой предмет, перезайти | Размер, ограничения, сохранность после рестарта |
| Донат | Открыть магазин в обычном браузере, выбрать #1, раскрыть товары | SKU, цена, срок, состав, дата снимка, условия выдачи |
| Привилегии | Сравнить публичные описания рангов и доступные команды | Матрица free/paid; непроверенные функции пометить |
| Правила | Прочитать опубликованный документ и закрепленные сообщения | Дата редакции, ограничения MAX4, рейды, вайпы, возвраты |
| PvP и база | Изучить разрешенные игровые действия на собственной тестовой базе | Стоимость рейда, повреждения, decay; без вреда чужой базе |
| Сообщество | Посмотреть открытые объявления и события | Реальное расписание, частые жалобы, ответы администрации |

Если магазин требует Steam-входа, владелец проекта может просмотреть его собственным аккаунтом. Учетные данные передавать агентам не требуется. Ни одна проверка не требует покупки ради исследования.

## 10. Что считать результатом аудита

Для планирования MRE уже определены нужный PEI-референс, различия #1/#6, публичные Workshop ID, контуры систем и ограничения переиспользования ресурсов. Дальнейшие технические задачи нужно ставить по функциям и приемочным сценариям, а не как «скопировать DLL REDLINE».

Полноценный финал исследования — заполненная матрица реальных возможностей бесплатного игрока и каждой продаваемой роли, подтвержденное расписание вайпов, протестированные задержки телепортов, размер vault и список прав. До этих проверок обещание точного совпадения с REDLINE было бы недостоверным.

Сроки и бюджет реализации MRE должны отдельно учитывать сопровождение, резервное копирование, комиссии магазина и работу владельца. Ни слотность референса, ни единичный онлайн мониторинга не дают достоверного прогноза выручки нового сервера.
