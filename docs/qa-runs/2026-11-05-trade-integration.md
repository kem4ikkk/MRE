# Проверка объединения веток обмена

Дата: 5 ноября 2026 года. Серверный обмен из `feature/player-trade` и UI из `feature/trade-ui` объединены с текущим состоянием MRE в отдельной рабочей копии. Пользовательские изменения другой сессии и работающий сервер не затронуты.

Плагин собран против локального U3DS, Rocket и Teleportation. Прошли изолированные проверки состояний обмена и повторного добавления, статическая проверка исходников UI и 64 проверки установщика с фиктивными файлами. Исправлены кодировка скриптов для Windows PowerShell 5.1 и чтение UTF-8 в проверке UI.

Добавлен предохранитель `ExperimentalTradeEnabled=false`: при стандартных настройках команды обмена и уже открытые сессии не разрешают передачу. Проверка интерфейса Unity и браузерного preview не выполнена: Unity Editor в стандартных каталогах не обнаружен, модуль Playwright в окружении отсутствует. Workshop-пакет обмена не опубликован.

Сохранение двух инвентарей и журнала остаётся неатомарным, возможны потеря или дублирование предметов после аварии; рейдовая блокировка не покрывает все сценарии. Игровой прогон двумя клиентами, проверка Harmony, проекции инвентаря и аварийного восстановления не проведены. До их успешной приёмки и исправления сохранности не включать функциональность на публичном сервере и не использовать ценные вещи. Предохранитель не решает проблему атомарности.
