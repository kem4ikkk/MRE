# Подсказка скорости гниения построек

Подсказка задумана как небольшая постоянная строка снизу экрана. Она появляется, пока игрок держит Housing Planner или распознанную строительную часть. Статус определяется по поверхности под прицелом и обновляется при смене зоны. Если предмет убран, под прицелом нет цели либо механика гниения или карта зон не готовы, строка скрывается.

Тексты:

- `Постройка гниёт быстрее — 2% / 5 мин`
- `Постройка гниёт с обычной скоростью — 1% / 5 мин`

Спальник не участвует. Обычные инструменты и хранилища не считаются строительными предметами. В локальных игровых ресурсах Housing Planner подтверждён; отдельный House Upgrader не найден, поэтому неизвестный инструмент не классифицируется автоматически.

Код политики, выбор точки прицеливания и игровой адаптер находятся в `src/MreDecayZoneHud`. Внешний Unity UI использует `DecayZonePanel` и `DecayZoneText`. Проверки на заглушках запускаются командой `dotnet run --project tests/MreDecayZoneHud/MreDecayZoneHud.csproj --configuration Release`; компиляция против локальных DLL игры — `dotnet build tests/MreDecayZoneHud/GameBuild/GameBuild.csproj --configuration Release`.

**Состояние подключения:** адаптер ещё не подключён к серверному плагину, а рабочий источник состояния decay и подтверждённая геометрия зон отсутствуют. Поэтому текущая сборка безопасно скрывает строку в игре; она не может пока сообщать фактическую скорость. Экспериментальный эффект и клиентская доставка также не установлены. Не публиковать до подключения проверенного источника и игровой проверки.
