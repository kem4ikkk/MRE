# Черновая разметка PEI

Запуск из корня: `python tools/pei-decay-zones/server.py`, открыть `http://127.0.0.1:8765/`, остановка Ctrl+C. Сервер слушает только localhost и читает оригинальные `Chart.png` и `Level.hierarchy` из runtime; файлы не копируются и не изменяются. JSON скачивается браузером, сервер ничего не записывает.

Преобразование основано на [SDG U3-SDK, PlayerDashboardInformationUI.cs](https://github.com/SmartlyDressedGames/U3-SDK/blob/main/Assets/Runtime/Assembly-CSharp/Unturned/UI/Player/PlayerDashboardInformationUI.cs), `ProjectWorldPositionToMap`: позиция в локальных координатах CartographyVolume переводится в `(x + 0.5, 0.5 - z)`. Поддерживается только один CartographyVolume формы Box с единичным quaternion и положительным scale; другие случаи отклоняются. В установленной PEI найдена одна запись ID 8. Вместе с координатами экспортируются точные строковые значения transform и SHA-256 канонического JSON объёма, а также хеши исходной карты и Chart.png.

Владелец выбрал все 21 отмеченные точки, включая локации, не являющиеся городами. Результат обозначен DRAFT и не применяется автоматически. При импорте и экспорте отклоняются повторные вершины, самопересечения и нулевая площадь; охват территории, совпадение изображения и проекции и границы в игре не проверяются автоматически. Игровая приёмка не выполнена.

Кнопка импорта читает выбранный JSON только в браузере. Статус DRAFT, хеши карты/изображения/объёма, точный набор ID и имён, конечность и нахождение вершин в пределах изображения проверяются до замены текущей разметки; при ошибке она остаётся прежней. Это проверка формата, а не приёмка геометрии.

`python scripts/Render-MrePeiZoneDraft.py` создаёт `planning/pei-decay-zones-draft.png` с пронумерованными предварительными зонами и легендой; для него требуется Pillow и локальная карта с ожидаемым хешем. Изображение предназначено для обсуждения и не является игровой конфигурацией.

Для одной локации можно нарисовать несколько отдельных полигонов: выберите область в списке, добавьте или удалите её кнопками. Очистка и отмена вершины действуют только на выбранную область. Каждый полигон должен содержать 3–256 вершин; допускается до 256 полигонов на локацию. Пересечения между отдельными полигонами не проверяются.

Экспорт редактора записывает `polygons` как массив массивов координат `{x, z}`. Старый черновик с `vertices` импортируется как один полигон; наличие обоих полей одновременно отклоняется. Этот формат предназначен для редактора и не является конфигурацией сервера: другим инструментам, ожидающим `vertices`, потребуется обновление. После импорта файл можно сохранить в новом формате.
