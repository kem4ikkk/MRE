# MRE меню: растровые значки

15 PNG-спрайтов получены из исходных векторных символов [`ui/preview/menu-shell/icons.svg`](../../../../preview/menu-shell/icons.svg) этого репозитория. Использована исходная геометрия без изменений: viewBox `0 0 24 24`, белая обводка толщиной 2, круглые окончания и соединения. Размер каждого файла — 128×128 px, фон прозрачный.

Рендерер — локальный Playwright с установленным Microsoft Edge; сеть и сторонние изображения не используются. Воспроизведение из корня репозитория:

```powershell
node ui/MreHelp/Assets/MreMenuArt/shell/generate.js
```

Файлы Noto Sans и PT Sans, используемые интерфейсом MRE, находятся в `ui/MreHelp/Assets/MreFonts/`; значки шрифт не используют.


Маски `round-{8,12,16,20}.png` — собственные белые маски скруглений для Unity nine-slice, создаются `generate-rounds.py` через Pillow. Они сохраняют радиусы и ровный цвет поверхностей, без серой встроенной текстуры Unity.
