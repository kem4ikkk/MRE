# Физический полет администратора MRE

Обновлено 30.10.2026. MreFlight 0.1.0 — отдельный GPL-3.0-only плагин, выделенный из механики полета [ShimmysAdminTools](https://github.com/ShimmyMySherbet/ShimmysAdminTools). Происхождение, точный commit, авторство, изменения и соответствующий исходный код указаны в [UPSTREAM.md](../src/MreFlight/UPSTREAM.md). Полная лицензия сохранена в `src/MreFlight/LICENSE`.

## Управление

| Команда/действие | Результат |
|---|---|
| `/afly on` | Включить физический полет своего персонажа; повтор оставляет режим включенным |
| `/afly off` | Выключить; повтор не включает полет обратно |
| `/afly` или `/fly` | Переключить режим |
| WASD | Обычное горизонтальное движение в режиме полета |
| Клавиша прыжка | Подъем через отрицательный серверный множитель гравитации |
| Клавиша спринта при взгляде вниз | Спуск; при отпускании — остановка вертикального движения |
| `/aflyspeed <число>` | Горизонтальный множитель 0.1–10 |
| `/aflyvspeed <число>` | Вертикальный множитель 0.1–5 |

По умолчанию оба множителя равны 1. Числа вводятся с точкой; NaN, Infinity, нулевые и выходящие за пределы значения отклоняются. Используются текущие штатные назначения прыжка и спринта. Plugin0/1 и другие plugin hotkeys не читаются: Б/Ю остаются у TPA.

MreFlight перемещает тело персонажа. Native freecam на LeftShift+F1 перемещает камеру и остается отдельной функцией. Полет не включает неуязвимость или невидимость автоматически. После выключения восстанавливается обычная физика с теми множителями, которые действовали до включения; персонаж продолжает участвовать в игровом мире.

## Права и жизненный цикл

Для включения и изменения скорости требуются одновременно `mre.admin` и `mre.admin.fly`; native администратор, включая подтвержденного владельца, проходит проверку через `IsAdmin`. Проверяется реально подключенный объект игрока и главный игровой поток. Управлять полетом другого игрока эти команды и API не позволяют.

Выключение собственного режима остается доступным после отзыва прав. Команда `afly` поэтому не полагается на внешнюю permission-проверку Rocket: включение проверяется внутри API. Права проверяются повторно каждый FixedUpdate. При отзыве права, смерти, выходе, смене сессии, входе в транспорт или выгрузке плагина режим прекращается. Прежние gravity/speed/jump сохраняются отдельно при включении и восстанавливаются точно, а не заменяются константой 1. Исключение при тике отключает режим и записывается в закрытый журнал.

## API для общей админки

Пространство имен `MreFlight`. Публичный `MreFlightPlugin.Instance` равен `null` до загрузки и после выгрузки.

| Вызов | Контракт |
|---|---|
| `SetFlight(UnturnedPlayer actor, bool enabled)` | Русская строка результата; on/off идемпотентны; повторная проверка полномочий при включении |
| `IsFlying(UnturnedPlayer actor)` | Состояние собственного текущего объекта игрока |
| `SetSpeed(UnturnedPlayer actor, float horizontal, float vertical)` | Изменить оба множителя активного полета с проверкой прав и пределов |
| `GetSpeed(UnturnedPlayer actor)` | Новая пара текущих множителей; при отсутствии разрешенной сессии 1/1 |

Все вызовы выполняются на главном игровом потоке; иначе выбрасывается `InvalidOperationException`. Общая админка может маршрутизировать фиксированные `afly on/off` через менеджер команд Rocket. Нельзя передавать произвольный текст консоли или чужого actor, полученного от клиента.

## Сборка и подтвержденные проверки

```powershell
.\scripts\Build-MreFlight.ps1
dotnet run --project src/MreFlight/Tests/MreFlight.Tests.csproj --configuration Release
```

Сборщик использует DLL установленного U3DS/LDM и создает только `runtime/builds/MreFlight/MreFlight.dll` и `build-manifest.json`. Манифест включает SHA256 исходников, результата и зависимостей, GPL-лицензию и upstream commit. Рабочий сервер сценарий сборки не меняет.

Подтверждены компиляция против текущего SDK и 17 проверок состояния: подъем/спуск/остановка, определенный приоритет одновременных действий, изменение скорости, отзыв прав, смена сессии, повторный выход, независимость сохраненных значений и отказ неверных скоростей. Эти проверки не запускают Unturned и не подтверждают реальную клиентскую синхронизацию. Вход владельца, движение тела, отпускание клавиш, приземление и соседство с другими модификаторами движения требуют игровой приемки после установки.

Старый полный релиз ShimmysAdminTools v1.7.2a и его исходники отдельно скачаны в игнорируемый `runtime/optional-plugins/ShimmysAdminTools/`. Неизмененные 85 исходных файлов не собираются против текущего SDK: отсутствуют старые `ERagdollEffect.GOLD` и `NONE`. Это еще одна причина проверять выделенный модуль отдельно. В MreFlight отсутствуют updater, произвольный Exec, бесконечные патроны, массовое удаление и прочие команды полного исходного проекта.
