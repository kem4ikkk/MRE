# Административные команды MRE

## Телепорт по метке

Игровой администратор может поставить личную метку на карте и выполнить `/admin marker` (при конфликте команды — `/mreadmin marker`). Нужен живой персонаж вне транспорта и режима наблюдения. Сервер проверяет положение метки, поверхность, воду и свободное пространство. Луч сверху может выбрать крышу; фактическую посадку требуется проверить в игре. Команда обходит обычную задержку телепортации и недоступна игрокам, у которых есть только Rocket-права без native admin.

`MreAdminTools` предоставляет административную выдачу предмета и создание транспорта. Команды и публичный API используют одну серверную реализацию проверок и действий. Само наличие команды не назначает права: их настройка остаётся обязанностью администратора сервера.

## API для UI

- `MreAdminToolsPlugin.Instance.GiveItem(UnturnedPlayer actor, ulong targetId, ushort itemId, byte amount)` — возвращает русское сообщение об успехе или отказе. `targetId` — точный SteamID64 игрока, который должен быть сейчас подключён.
- `MreAdminToolsPlugin.Instance.SpawnVehicle(UnturnedPlayer actor, ushort vehicleId)` — возвращает русское сообщение; транспорт создаётся штатным `VehicleTool.SpawnVehicleForPlayer` рядом с actor.

Оба метода проверяют, что actor подключён, работает экземпляр плагина и вызов выполняется на главном игровом потоке. Actor должен быть native admin либо иметь соответствующее отдельное право. UI должен передавать доверенный `UnturnedPlayer` из серверного контекста; клиентский ID не является actor. Метод выдачи не допускает переполнения: он сначала находит место на личных страницах инвентаря, а при отсутствии места отказывает без выдачи.

## Команды и права

| Команда | Аргументы | Permission node |
| --- | --- | --- |
| `/give` | `<SteamID64> <ID предмета> <количество>` | `mre.admin.give` |
| `/veh` | `<ID транспорта>` | `mre.admin.veh` |

`/give` принимает только числовой SteamID64 уже подключённого игрока, положительный ID предмета и количество от 1 до максимального стака `ItemAsset.amount`. Имя и частичный поиск не поддерживаются. `mre.admin.give` не предоставляет другие административные права.

`/veh` требует существующий vehicle asset и живого подключённого actor. Координаты рассчитываются игровым серверным `VehicleTool`, а не передаются клиентом.

## Проверенная поверхность SDK и сборка

Подписи сверены по локальному SDK текущей установки `runtime/server/Unturned_Data/Managed/Assembly-CSharp.xml` и используемым SDK типам:

- `SDG.Unturned.VehicleTool.SpawnVehicleForPlayer(SDG.Unturned.Player, SDG.Unturned.Asset)` — штатный серверный helper поддерживает vehicle redirectors.
- `SDG.Unturned.VehicleManager.spawnVehicleV2(System.UInt16, UnityEngine.Vector3, UnityEngine.Quaternion)` существует, но не используется: helper выше сам отвечает за безопасное размещение относительно игрока.
- `Assets.find(EAssetType, ushort)`, `ItemAsset.amount`, `Items.tryFindSpace(...)`, `PlayerInventory.tryAddItem(...)`, `VehicleManager.vehicles` и `Item(ItemAsset, EItemOrigin)` сверяются локальной компиляцией из [Build.ps1](../src/MreAdminTools/Build.ps1); определения этих членов в XML документации неполные.

Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File src/MreAdminTools/Build.ps1`. DLL и `build-manifest.json` создаются в `runtime/builds/MreAdminTools`. Манифест содержит фактический SHA256 DLL и SHA256 использованных SDK references. Этот каталог предназначен для локальной сборки и передачи как reference следующему build шагу; модуль не устанавливается в `runtime/server`.

## Проверки и ограничения

- Реализация включает раздельные права, native admin, подключённость actor и target, поиск asset, лимит стака, отказ при полном инвентаре, живое состояние actor для транспорта и журналы успешных действий без секретов.
- Build.ps1 успешно скомпилировал модуль с установленным SDK; это не проверяет появление предмета/машины в игре. Игровой smoke test и присвоение прав не выполнялись.
- `/give` ищет свободное место на личных страницах инвентаря; он намеренно не использует внешнее хранилище, экипировочные слоты или дроп на землю.
