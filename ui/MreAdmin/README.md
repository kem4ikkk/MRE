# MRE Admin Effect

Откройте этот каталог в Unity 2022.3.62f3 и выполните `MRE → Admin → Собрать Windows bundle`.
Unity создаст prefab из `Assets/Editor/MreAdminBuilder.cs`, проверит адрес `Effect` и положит локальную сборку в `runtime/ui-builds/MreAdmin/Windows/MreAdmin/`.
Контракт: Effect ID `48626`, key `14826`, GUID `bc15863fb9c24a69a36bb733456cc3b2`.
В рабочей среде Unity без действующей лицензии отказал с `No valid Unity Editor license found`; для получения bundle нужна лицензированная Unity установка.
Это bundle-effect для Unturned, а не публикация в Workshop и не подтверждение, что игровой клиент его принял.
