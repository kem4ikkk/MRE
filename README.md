# MRE — Unturned PEI

Самостоятельный бюджетный проект по образцу **REDLINE #1**: PvP-выживание, группы до четырех игроков, HOME/TPA; VAULT входит в следующий этап после проверки хранения. Страна приема платежей — Россия. Состояние обновлено 30.10.2026.

Репозиторий: [kem4ikkk/MRE](https://github.com/kem4ikkk/MRE). Сообщения коммитов и описания изменений — на русском языке.

**Статус:** локальная бета установлена и запущена: PEI, Easy, MAX4, 24 слота, HOME/TPA, More Farming, William's Vehicles, собственные `/vote day` и автосохранение. Проверены серверная загрузка, A2S, сохранение, остановка и восстановление копии. Вход игроков и игровые сценарии еще не прошли полную приемку. Магазин и VAULT не подключены.

## Подключение и управление

На этом компьютере подключение в Unturned: **127.0.0.1**, порт **27015**. Пароль хранится локально в `secrets/mre.local.json` (`JoinPassword`); файл не отправляется в Git. Для друзей можно использовать текущий Server Code из `runtime/server/Logs/Server_MRE.log`; без GSLT он меняется после перезапуска.

```powershell
.\scripts\Start-MreServer.ps1 -WaitForReady -TimeoutSeconds 240
.\scripts\Test-MreServer.ps1
.\scripts\Send-MreServerCommand.ps1 -Command Diagnostics
.\scripts\Stop-MreServer.ps1
```

Повторно запускать уже работающий сервер не нужно. Это закрытая локальная бета в режиме LAN; внешнее подключение и публичный режим проверяются отдельно. Порядок установки с нуля, версии и результаты — в [отчете об установке](docs/LOCAL_INSTALLATION.md).

Рабочий ориентир: один сервер на 24 слота, аренда примерно 650–1100 ₽/месяц, резерв 3000–4500 ₽ на первые три месяца. Полные расходы зависят от провайдера, копий, платежной схемы и необходимости разработки недостающих функций. Начальная аудитория и продажи не гарантируются.

В исследовании использованы все **4 доступных одновременных агента**, включая координатора. Перечень из 16 ролей — специализации для следующих этапов; он не означает 16 параллельных процессов или установленных серверных ботов.

Для локальной проверки начать с [отчета об установке](docs/LOCAL_INSTALLATION.md). Следом — проверка двумя игроками, VAULT и подготовка магазина по [полному плану](docs/IMPLEMENTATION_PLAN.md). Тарифы перепроверяются перед оплатой.
