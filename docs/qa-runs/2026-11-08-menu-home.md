# Главная меню и удаление разделителя — 08.11.2026

Владелец подтвердил отображение оболочки в игре скриншотом и попросил убрать палочку у уведомлений, затем продолжить работу по разделам. Удалён `MenuHeaderDivider`, который пересекал кнопку колокольчика. Следующий этап выполнен только для Главной: профиль игрока, сведения о сервере и четыре навигационные карточки. Остальные девять страниц остаются пустыми. Noto Sans Regular/SemiBold, цвета, логотип и внешняя геометрия сохранены.

## Данные

`HomeData` читает ник и SteamID64 владельца UI, `Player.quests.groupID`, `GroupManager.getGroupInfo(...).name`, `Provider.clients`, `Provider.maxPlayers`, `Provider.serverName` и `Level.info.name`. Эти API подтверждены метаданными установленной Assembly-CSharp, затем DLL собрана по реальным references. Полный состав с офлайн-игроками не заявляется: счётчик группы подписан «В сети».

Название сервера сокращено до первого `|`, чтобы не повторять карту и режим в заголовках. Пустая или недоступная группа не подменяется вымышленным названием. Управляющие символы, форматирующие символы и rich-text теги в пользовательских строках обезвреживаются; Text.supportRichText=false. Очень длинные широкие имена могут обрезаться внутри своего поля; приёмка таких имён в игре ещё нужна.

Личные данные отправляются только на соединение владельца сессии. Обновление выполняется каждые пять секунд на игровом потоке, исключительно для открытых Главных. От сторонних собственных DLL зависимости нет. Быстрые карточки переключают вкладки; невидимые кнопки Главной на других страницах игнорируются.
