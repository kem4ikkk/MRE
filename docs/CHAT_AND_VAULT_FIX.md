# Чат и открытие `/s` — 1 ноября 2026

## Изменения

`/kits` показывает одну строку со списком имён, например `Наборы: start`. Плагин `MreChatStyle` перехватывает серверные сообщения для конкретного получателя: подпись выделена зелёным, текст — белым, иконка заменяется прозрачным PNG MRE. Игровые сообщения от игроков, их получатели и канал не меняются. Чужая rich-text разметка в серверных сообщениях удаляется до применения безопасного оформления; угловые скобки текста не превращаются в команды оформления. Длинные сообщения из отдельных плагинов могут уже быть разбиты на строки до этого обработчика.

По запросу владельца значок заменён на финальный логотип сервера MRE с прозрачным внешним фоном. Файл опубликован в `feature/transparent-chat-icon`, commit `994f96f53de120df31ae81d76e578ed6597371bb`; публичный PNG проверен по SHA256. Публичная ссылка зафиксирована на коммите; перед удалением этой ветки следует перенести изображение в сохраняемую ветку и повторно проверить адрес. Новая иконка имеет альфа-канал, её отображение в конкретном игровом клиенте ещё нужно подтвердить.

`/s` раньше открывал фиктивный багажник: `openTrunk` помечает хранилище как багажник, а клиент для него не открывает инвентарь автоматически. Теперь сервер назначает контейнер с признаком обычного хранилища и отправляет его игроку. Условия доступа, обработчики переноса и сохранение прежние. В U3-SDK проверены `PlayerInventory.openStorage`, `openTrunk`, `sendStorage`, `closeStorage` и `PlayerDashboardInventoryUI.onInventoryStored`; версия установленной игры должна проверяться в клиенте. Источники: [PlayerInventory.cs](https://github.com/SmartlyDressedGames/U3-SDK/blob/main/Assets/Runtime/Assembly-CSharp/Unturned/Player/PlayerInventory.cs), [PlayerDashboardInventoryUI.cs](https://github.com/SmartlyDressedGames/U3-SDK/blob/main/Assets/Runtime/Assembly-CSharp/Unturned/UI/Player/PlayerDashboardInventoryUI.cs), [документация rich text](https://docs.smartlydressedgames.com/en/stable/data/rich-text.html).

## Проверки и установка

- Новые DLL MreChatStyle, MreKits и MreVault собраны против локального U3DS/LDM. Форматирование прошло семь проверок, включая списки наборов и постороннюю разметку. Тесты MreKits — 15 PASS; тесты файла и ограниченного журнала VAULT — PASS; установщик — 36 PASS на фиктивном экземпляре.
- Сервер штатно сохранил мир и остановился, создана проверенная копия `backups/MRE-before-chat-vault-20261101-032940-4267.zip` с манифестом. Установлены только три новые DLL; SHA256 установленных Essentials, HUD, Teleportation, MoreHomes и Interface не изменился.
- После запуска загружена PEI, A2S ответил; Rocket загрузил MreChatStyle и зарегистрировал `/kits` и `/s`. Локальный Diagnostics выполнен успешно. Регистрация команды не доказывает работу окна и отображение цветов/иконки у клиента.
- Перед заменой иконки на финальный логотип создана резервная копия `backups/MRE-before-logo-20261101-101406-4022.zip`. Установлен только обновлённый MreChatStyle; хеши MreKits, MreVault, Essentials, HUD, Teleportation, MoreHomes и Interface совпали с копией. Сервер вновь загрузил PEI, ответил на A2S, Diagnostics завершился успешно.

Владелец сообщил, что игровые проверки `/s`, списка `/kits`, цветов и прозрачности прежней иконки работают. После этого иконка заменена на логотип MRE; она ожидает проверки в клиенте. При этом отдельные аварийные сценарии и восстановление не проверены. Аварийная согласованность VAULT не решена: использовать только тестовые предметы, не подключать продажу и не хранить ценные вещи. На момент первоначальной проверки GPT-6.1 Sol не запускался. Исходники исправления и иконки фиксируются в общем коммите проекта.
