# Noto Sans для меню MRE

В меню используются статичные hinted TTF Noto Sans Regular и SemiBold с кириллицей. Начертание выбирается отдельным файлом шрифта; синтетическое утолщение Unity отключено.

Источник: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Лицензия: SIL Open Font License 1.1; текст — `NotoSans-OFL.txt`. Загружено 08.11.2026 из официального архива проекта Noto.
