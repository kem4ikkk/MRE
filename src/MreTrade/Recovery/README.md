# Офлайн-просмотр журнала обмена

`Inspect-MreTradeJournal.ps1` только читает отдельный файл `.pending` или `.done`, проверяет размер, SHA-256, версию и ограничения количества записей и выводит JSON в локальную консоль:

```powershell
powershell -NoProfile -File .\src\MreTrade\Recovery\Inspect-MreTradeJournal.ps1 -JournalPath 'D:\путь\к\копии\операция.pending'
```

Работайте на копии при остановленном сервере; сохраните оригиналы журнала, логов, сохранений обоих игроков и согласованной резервной копии. Вывод содержит SteamID и состояния предметов: не публикуйте его. SHA-256 выявляет повреждение, но не подтверждает подлинность файла. Снимки относятся к моменту **до** передачи, а план и `.done` не доказывают содержимое сохранений после аварии. Инструмент не сравнивает мир или инвентари, не возвращает вещи и не разрешает удаление блокировок. Для разрешения каждого случая нужна ручная сверка; автоматическое восстановление по этим данным небезопасно. Проверка в реальной игре и после аварии не проводилась.

Самопроверка на синтетических данных:

```powershell
powershell -NoProfile -File .\src\MreTrade\Recovery\Test-Inspect-MreTradeJournal.ps1
```
