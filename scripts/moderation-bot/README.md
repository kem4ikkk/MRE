# Необязательный Discord-бот MRE

Собственный бот для просмотра профиля, истории наказаний и прежних имен. Он читает JSON MreModeration с диска и не меняет права, инвентари или игровые сохранения. Подключение не выполняется до настройки владельцем.

## Установка

Из корня репозитория:

```powershell
python -m venv runtime/moderation-bot-venv
runtime/moderation-bot-venv/Scripts/python.exe -m pip install -r scripts/moderation-bot/requirements.txt
Copy-Item config/moderation-bot.example.json secrets/mre-moderation-bot.json
```

Нужны созданное владельцем приложение Discord, Bot Token, ID своей гильдии и разрешенные StaffRoleIds. Реальные значения хранятся только в `secrets/mre-moderation-bot.json`; токен также можно передать через `MRE_DISCORD_TOKEN`. Не включать привилегированный Message Content Intent: бот обрабатывает slash-команды.

Права приглашения приложения: `bot` и `applications.commands`; доступ дать только нужному серверу Discord. Код проверяет GuildId и роль при каждом запросе. Допускаются администраторы указанной гильдии либо перечисленные staff-роли; личные сообщения и другие гильдии отклоняются. Ответы ephemeral, упоминания отключены. Список staff-ролей не связан автоматически с игровым донатом или Steam-владельцем.

После первого сохраненного профиля MreModeration:

```powershell
runtime/moderation-bot-venv/Scripts/python.exe scripts/moderation-bot/bot.py
```

`/mre_profile steam_id`, `/mre_history steam_id`, `/mre_names steam_id`. Команды регистрируются только в настроенной гильдии. Бот работает на том же компьютере с доступом к приватным файлам сервера; отдельная аренда и внешняя БД для этого варианта не требуются. При закрытии процесса бот прекращает работу. Автозапуск добавляется владельцем после проверки приложения.

## Проверки и ограничения

Шесть автономных тестов: формат/SteamID, запрет обхода пути, совместимость схемы, права разных гильдий, исключение приватных полей и совместное чтение с `ReplaceFileW` Windows. Последняя проверка подтверждает, что чтение не мешает атомарному сохранению игровым сервером.

```powershell
python -m unittest discover -s scripts/moderation-bot -p "test_*.py"
```

Чаты, команды, IP и произвольные поля не выводятся ботом. Время обозначено UTC. Trustscore не вычисляется повторно в боте, чтобы формула не расходилась с плагином. Бот не является заменой защищенного игрового API и не позволяет проводить удаленные наказания. Токен/гильдия не настроены в рамках разработки; регистрация команд и доставка Discord не проверялись. Наличие исходников не означает подключенную интеграцию.

Зафиксированная `discord.py 2.7.1` проверена 30.10.2026 по [официальным метаданным PyPI](https://pypi.org/project/discord.py/) и [документации interactions](https://discordpy.readthedocs.io/en/stable/interactions/api.html). Лицензия библиотеки MIT; ее пакет устанавливается отдельно.
