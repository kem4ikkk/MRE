# Исправление шрифта HUD, логотипы и голосование — 05.11.2026

После установки компактного HUD пользователь обнаружил пропавшие подписи, слипшиеся цифры и слишком мелкое оружие. Причина обрезки текста подтверждена: высота нескольких полей была меньше строки нового шрифта. Проверки глифов без рендера не выявили проблему. Переменный шрифт заменён статическими PT Sans Regular/Bold, поля исправлены, панель оружия увеличена до 220×76. Для чисел урона возвращён встроенный LegacyRuntime с сохранением цветов, минуса и чёрной обводки.

Для PvP-блока добавлены оригинальные перекрещённые клинки, для рейд-блока — расколотый щит. Изображения генерируются редактором из многоугольников. Окно голосования переработано: справа по центру, 264×108, заголовок «Смена дня», таймер, варианты «ЗА» и «ПРОТИВ» с реальными настроенными клавишами и цветом личного выбора. Правила голосования остаются в MreEssentials.

Проверки: 32 автоматических сценария HUD; успешная сборка Unity 2022.3.62f3; повторная загрузка bundle; непустые текстовые mesh и конечные UV; визуальный просмотр рендера 1920×1080. Рендер содержит примерные значения. До добавления последних логотипов и карточки проведено независимое ревью Terra/Sol; последние изменения координатор собрал и просмотрел сам, поскольку агенты достигли лимита. Игровое отображение нового пакета, High-раскладка, все длинные имена и изменённый масштаб UI ещё требуют приёмки.

Workshop 3832074683 принял обновление с SHA256 `6550e0f6873565ed22b62eff232b667009c42688d5c8bd582c05482dfc162222`. Лицензия PT Sans приложена к пакету. Перед установкой сохранён экземпляр `backups/MRE-before-hud-final-release-20261105.zip`, предыдущее содержимое Workshop — `backups/workshop-hud-before-final-font-20261105`. Откат ресурса выполнять при остановленном сервере с обновлением той же работы Workshop.

Статистика, полноценное интерактивное `/top` и показатели брони остаются отдельной незавершённой задачей. Новый HUD умеет необязательно читать MreStats; без него плашки скрыты. Не выдавать подготовленные макеты и текстовый прототип `/top` за установленное меню.
