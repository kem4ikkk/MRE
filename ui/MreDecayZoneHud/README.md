# Подсказка зоны гниения

Собственный изолированный Unity-исходник: небольшая строка снизу экрана, узлы `DecayZonePanel` и `DecayZoneText`. Изначально панель скрыта. Внешний вид ориентирован на действующий MRE HUD. Для проверки отдельно использовать `MreDecayZoneHudBuilder.BuildVisualBundle`, передав существующий тестовый каталог в `MRE_DECAY_HUD_OUTPUT`.

Политика в `src/MreDecayZoneHud/HintPolicy.cs` показывает 2% в ускоренной зоне, 1% вне её и отдельный текст при неизвестной зоне; при обычном предмете или отключении игрока подсказка скрыта. `HintController` скрывает её при отключённой механике и выгрузке, обновляет при переходе границы, не пересылает неизменившееся сообщение и не подменяет проверку готовности механики вызывающим адаптером. Неопределённый результат отправки сначала очищается перед повторной попыткой; ошибка очистки одного игрока не мешает попытаться очистить остальных. Классификатор отличает Housing Planner по игровому useable type, конструкции и подходящие строительные баррикады от обычных инструментов и хранилищ. Перечень строительных баррикад требует игровой проверки, особенно для Workshop. Проверка с игровыми заглушками: `dotnet run --project tests/MreDecayZoneHud/MreDecayZoneHud.csproj --configuration Release`.

05.11.2026 исходный проект скопирован в отдельный временный каталог и собран Unity 2022.3.62f3 для Windows. Редактор повторно открыл bundle и нашёл Canvas с `DecayZonePanel/DecayZoneText`; маркер `MRE_DECAY_ZONE_BUNDLE_OK`, код завершения 0, SHA-256 `8da76a1b4f574ecaa4d9d14d584d64ec64308635c09ad09328e911e3a7ad4654`. В журнале также были ошибки обновления Unity license token и TLS; сам факт создания и чтения bundle не доказывает, что лицензирование было полностью без ошибок. Классификатор отдельно скомпилирован против установленных DLL игры в TEMP.

Для изолированной сборки назначен временный контракт Effect ID 48623, key 14823 и GUID `5d4628c25c73441a89ef5aed4db47713`. Уникальность среди всех серверных и клиентских Workshop-ресурсов до рабочего применения не подтверждена. Серверный плагин и доставка клиенту пока не подключены. Bundle сам по себе не подтверждает отображение в Unturned, проверку предмета в руке или попадание в зону. Ресурс не установлен и не опубликован.

Подготовлены `EffectHintSink` и `UnturnedEffectTransport`: при появлении подсказки эффект создаётся, получает текст и включает панель; при смене зоны текст обновляется без повторного создания, при скрытии эффект очищается. Неизвестный исход создания и ошибка очистки остаются доступны для повторной очистки через `HintController`. Транспорт скомпилирован против локальных DLL игры без ошибок; вызовы дополнительно проверены на заглушках. Он ещё не подключён к плагину и не вызывался в игре. Вызывающий код должен разрешать именно текущее соединение, обрабатывать disconnect/reconnect и не включать подсказку до готовности механики. Эффект и клиентская доставка ещё не подготовлены; фактическая доставка не подтверждена.

Повторная компиляция против установленных DLL: `dotnet build tests/MreDecayZoneHud/GameBuild/GameBuild.csproj -c Release`. Она не устанавливает модуль на сервер.

`GameHintAdapter` обходит текущих игроков, классифицирует предмет и запрашивает зону через делегат, который должен возвращать false, пока настоящая механика не готова. Смена сессии, ошибки чтения и потеря готовности проверены на заглушках; при ошибке очистки подключённого клиента требуется повтор. Модуль ещё не вызван на сервере и не доказывает работу клиента. `powershell -ExecutionPolicy Bypass -File scripts/Build-MreDecayZoneHud.ps1` собирает экспериментальный `.dat` и bundle только во временном каталоге.
