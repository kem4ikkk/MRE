# Установка MRE Trade на изолированный тестовый сервер

Дата: 8 ноября 2026 года, время — Москва.

## Результат

- Сервер `runtime/trade-stage/server` штатно не работал перед установкой; основной MRE на порту `27015` не останавливался.
- Сборка `MreTrade.dll` для U3DS stage собрана через `scripts/Build-MreTrade.ps1 -GameDirectory runtime/trade-stage/server`.
- Обновлённый плагин установлен только в тестовый экземпляр. SHA-256: `d734eca92fea2d33757f0956a89f9c3c58d36dc19ad37e509c2f1e2633a20228`.
- В кэш stage помещён проверенный Workshop payload `3834982706`; SHA-256 `MreTrade.unity3d`: `873d3c07ba57b646787930c6283b50078fbccd508b2ce0d6997662eb58848b22`. Сервер сам обнаружил более свежую версию, скачал и установил её.
- Rocket загрузил `MreTrade` и зарегистрировал `/trade`; карта PEI завершила загрузку. A2S ответил именем `MRE Isolated Trade Test`, карта PEI, 0/4 игроков.
- `ExperimentalTradeEnabled`, `UiEnabled` и `AssetsVerified` оставлены `false`. Обмен не включён.
- Перед заменой DLL, конфигурации и Workshop-кэша сохранена копия в `runtime/trade-stage/backups/MreTrade-20261108-003639-993`.

## Проверки и границы результата

Статические проверки модели обмена, доставки, журнала восстановления, UI-контракта и Workshop payload пройдены до установки. Серверный журнал подтверждает только загрузку плагина, регистрацию команды и обновление Workshop. Вход игровым клиентом, показ окна UI и обмен двумя клиентами ещё не проверены. Основной сервер не менялся.

Для завершения приёмки нужны два разных Steam-аккаунта и тестовые предметы. До этого Trade должен оставаться выключенным.
