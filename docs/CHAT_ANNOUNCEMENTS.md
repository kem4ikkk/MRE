# Приветствие, подсказки и объявления MRE

При входе игрок получает личное сообщение с иконкой сервера: «Добро пожаловать на MRE! Введите `/help`, чтобы посмотреть команды сервера». Сообщения о входе и выходе по-прежнему видны всем игрокам.

`MreTips` отправляет подсказки в общий чат раз в 300 секунд, когда на сервере есть игроки. Подсказки используют логотип MRE и включают команды `/home`, `/tpa`, `/kits`, `/vote`, лимит группы MAX4 и советы о безопасной точке перемещения. Тексты находятся в `MreTips.configuration.xml`; действующая конфигурация Rocket хранит список отдельно от исходных значений по умолчанию.

Администратор с правами `mre.admin` и `mre.admin.announce` может отправить:

- `/admin announce event <текст>` — объявить событие всем игрокам;
- `/admin announce restart <минуты>` — предупредить о планируемом перезапуске.

Вторая команда только рассылает сообщение: она не запускает таймер, не сохраняет мир и не выключает сервер. Администратору нужно отдельно запланировать перезапуск и повторно отправить предупреждение, если время изменилось. Текст события ограничен 180 символами и публикуется через стандартное форматирование MRE.

Для изменения исходных текстов подсказок соберите `MreTips`; для изменений приветствия соберите `MreEssentials`; для команд объявлений — `MreInterface`. Скрипты сборки и установки: `scripts/Build-MreTips.ps1`, `scripts/Build-MreEssentials.ps1`, `scripts/Build-MreInterface.ps1` и `scripts/Install-MreChatStyle.ps1`.
