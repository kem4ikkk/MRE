# Добор аирдропов

Каждая категория получает собственный перемешанный пул. Пока все предметы пула не выданы, дубликаты из добора не появляются. После первого прохода пул повторяется в том же перемешанном порядке. Предметы, уже входящие в основной комплект, исключаются из добора. Пустые клетки заполняются предметами, подходящими по размеру; оружейный ящик может содержать предметы крупнее 1×1.

## Оружейный

Общий пул содержит 25 разных предметов: четыре тактических обвеса (151 Tactical Laser, 152 Tactical Light, 1007 Adaptive Chambering, 1008 Rangefinder) и 21 тип малых магазинов/боеприпасов для разных видов оружия (`20, 98, 100, 103, 108, 111, 113, 130, 298, 381, 478, 485, 489, 1003, 1020, 1022, 1040, 1361, 1368, 1384, 1487`). Только при наличии соответствующего оружия добавляются крупные совместимые магазины: 126→127 Nykorev, 132→133 Dragonfang, 1364→1365 Hell’s Fury, 1484→1485 Devil’s Bane. Для оружия с подходящим слотом добавляются 150 Military Muzzle к Dragonfang и 1190 Ranger Muzzle к Nykorev. Уже выпавшие в основном комплекте магазины исключаются из добора. Размеры предметов проверяются по загруженным `ItemAsset` и фактическому свободному месту ящика.

Обычные штатные прицелы исключены: ID 299, 1001, 134, 19, 128, 1383 и 1486. Другие прицелы в добор не добавляются.

## Строительный

Пул содержит 37 разных предметов: ресурсы и материалы `38, 40, 42, 64, 65, 66, 67, 69, 71, 72, 74, 285, 516, 1926`; элементы укрепления `365, 892, 893, 894, 1059, 1061, 1062, 1065, 1067, 1068, 1071, 1073, 1074, 1092, 1093`; ловушки и препятствия `382, 1101, 1102, 1227`; люки `1329, 1330, 1331, 1332`. Это расширяет строительный груз за пределы повторяющихся стопок материалов.

## Рейдовый

Основные комплекты включают ракетное оружие и заряды; добавлены варианты Shadowstalker с боеприпасами, у которых в локальных ассетах указано ненулевое повреждение построек. Добор включает взрывчатку, ловушки и прямые компоненты рецептов: `65 Wire`, `67 Metal Scrap`, `69 Tape`, `70 Glue`, `71 Nails`, `72 Metal Can`, `1242 Makeshift Grenade`, `254 Fragmentation Grenade`, `1100 Sticky Grenade`, `1520 Impact Grenade`, `1101 Landmine`, `1102 Claymore`, `1241 Demolition Charge`, `1393 Precision Charge`. Для комплектов Shadowstalker дополнительно учитываются совместимые боеприпасы `301 Rail` и `1443 Shadowstalker Mk. II Drum`; предметы основного комплекта не дублируются в доборе.

Ванильные `.dat` указывают для ID 301 и 1443 `Structure_Damage 50`, для 1100 и 1520 — 100, для 1241 — 1000, для 1393 — 2000. Фактический урон зависит от механик сервера и отдельно требует игровой проверки. Источники — локальные описания предметов и рецептов в `runtime/airdrop-isolated-dispatch-20261102/Bundles/Items`.

## Проверки

Перед созданием события плагин разрешает все ID через `Assets.find`, проверяет размер каждого предмета и моделирует размещение в настоящем asset ящика. Если комплект не помещается или обязательный asset отсутствует, аирдроп не запускается. Изолированные проверки: `dotnet run --project src/MreAirdrop/Tests/Filler/Filler.Tests.csproj` и `dotnet run --project src/MreAirdrop/Tests/MreAirdrop.Tests.csproj`. Реальное содержимое ящика и баланс проверяются на сервере.
